# CAPTCHASEC – Intelligent Human Verification

A static demonstration of an advanced CAPTCHA / human-verification system built with plain HTML, CSS and vanilla JavaScript. No frameworks, no build tools.

## Folder structure

```
captchasec/
├── index.html
├── css/
│   ├── tokens.css      ← design tokens (colours, fonts, spacing)
│   ├── base.css        ← reset & global styles
│   └── components.css  ← all component styles
├── js/
│   ├── main.js         ← app entry-point
│   ├── captcha.js      ← captcha challenge logic
│   ├── behaviour.js    ← user behaviour tracking
│   ├── scoring.js      ← risk scoring engine
│   ├── simulation.js   ← bot simulation
│   ├── storage.js      ← local persistence helpers
│   └── ui.js           ← DOM / theme helpers
├── assets/             ← images, icons, etc.
└── README.md
```

## Getting started

Open `index.html` in any modern browser — no server required.
